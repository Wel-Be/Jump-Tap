# Jump&Tap

Jump&Tap は、ハテナブロックをタップすると、Web Audio APIで生成したコイン獲得風の電子音が鳴るスマートフォン向けWebアプリです。

## ファイル構成

- `index.html` — アプリ画面
- `style.css` — デザインとレイアウト
- `app.js` — タップ動作・音声生成・音量調整
- `manifest.json` — ホーム画面追加用の設定
- `service-worker.js` — オフライン利用のためのキャッシュ
- `icon.svg` — アプリアイコン

## GitHub Pagesで公開する手順

1. GitHubで対象リポジトリを開きます。
2. このフォルダ内のファイルをリポジトリの公開元フォルダにアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** の Source を **Deploy from a branch** にします。
5. Branch で公開したいブランチ（通常は `main`）、フォルダは `/ (root)` を選択して保存します。
6. 公開URLを開き、ハテナブロック・効果音・音量スライダー・OFUSEリンクを確認します。

GitHub Pagesの設定画面やリポジトリの状態によって、公開URLが有効になるまで少し時間がかかることがあります。

## 更新方法

ファイルを編集してGitHubにコミットすると、GitHub Pagesに更新が反映されます。Service Workerのキャッシュを更新するときは、`service-worker.js` の `CACHE_NAME` の末尾のバージョンを変更してください（例：`jump-and-tap-v2`）。

## アクセス解析

GoatCounterの指定スクリプトを `index.html` に設定しています。ページビュー計測のため外部通信が発生します。タップ回数や音量操作は計測・送信しません。

## 音について

音はWeb Audio APIを使ってブラウザ内で生成します。参考音源の雰囲気を目指したオリジナル音であり、参照した音源ファイルをそのまま組み込むものではありません。

## 注意点

- オフライン動作は、オンラインで初回読み込みとキャッシュ登録が完了した後に利用できます。
- PWAのインストール方法やアイコン表示は、OS・ブラウザによって異なる場合があります。
- 音声再生はブラウザの制限により、ユーザーの最初のタップ後に開始される設計です。
